# O---CUBO
O Cubo é uma extensão de navegador que clona componentes, páginas e sites inteiros e devolve o código pronto em HTML, CSS, JavaScript, React e Tailwind. Também converte prints e mockups em código com IA (Gemini), além de extrair assets e links. Tem modo local, sem IA, e atalhos de teclado para agilizar o dia a dia de devs e designers.
